# PIP-110 [Android] Inflation default 5% + typed rate field

Ticket: https://linear.app/telco-paytm/issue/PIP-110/android-inflation-default-5percent-typed-rate-field

## Delivered

Inflation sheet (Define a goal → Inflation) defaults to **5%** with an editable numeric rate field; adjusted target live-updates. −/+ steppers remain as optional extras only.

| Type / file | Role |
|-------------|------|
| `data/model/Goal.kt` | `DEFAULT_INFLATION_RATE` 0.07 → **0.05** |
| `domain/GoalValidationService.kt` | Default alias; `parseInflationPercentInput` (0–30%); percent text helper |
| `ui/setup/InflationPopup.kt` | Typed `%` field + optional −/+; error UI; CTA falls back to 5% on invalid |
| `res/values/strings.xml` | Form + sheet copy 7% → 5%; `inflation_rate_error` |
| `domain/GrokService.kt` | Ask chip “Why is inflation 5%?” |
| `ui/goals/GoalDetailViewModel.kt` | Empty-state inflation label 5% |

## Mapping to Spec / PRD

| Requirement | Implementation |
|-------------|----------------|
| Default inflation 5% | `Goal.DEFAULT_INFLATION_RATE` / form + sheet copy |
| Typed rate field | `OutlinedTextField` with `%` suffix; KeyboardType.Decimal |
| Live adjusted target | `onRateChange` → host recomputes `liveAdjustedTargetPaisa` |
| Bounds / invalid | 0–30%; error supporting text; CTA / dismiss falls back to 5% |
| CTA “Use this rate” | Unchanged `PrimaryCta` |

## Acceptance criteria

- [x] Default inflation rate = **5%**; all copy that said 7% default updated to 5%
- [x] Rate is an editable numeric text field (user can type %); −/+ steppers optional extras only
- [x] Adjusted target updates live when the rate changes
- [x] Validate sensible bounds; invalid input → error UI; CTA falls back to 5%
- [x] Tests: validation parse + default; Ask chip/answer; `./gradlew :app:assembleDebug test --no-daemon`

## Reviewer checklist

1. New goals / form open with inflation **5%** (not 7%).
2. Form subtitle and Inflation sheet subtitle say **5%**.
3. Inflation sheet: typed rate field is primary; −/+ optional.
4. Typing a new rate live-updates Adjusted target; out-of-bounds shows error.
5. “Use this rate” with invalid/empty input applies **5%**.
