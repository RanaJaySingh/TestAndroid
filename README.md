# PiPlanner (Android)

Local demo of PiPlanner — goal-based savings ledger ("Every Rupee Has a Plan.").

## Stack

- Kotlin, Jetpack Compose, MVVM + UDF (StateFlow)
- Hilt, Coroutines/Flow, DataStore (JSON demo state)
- minSdk 26

## Build

```bash
./gradlew assembleDebug test
```

Open in Android Studio. GTS notes: `docs/gts/piplanner/`.
